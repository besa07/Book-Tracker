# Book-Tracker
GUI-приложение «Book Tracker» для управления списком прочитанных книг с возможностью фильтрации, сохранением данных в JSON и использованием Git.
# Book Tracker

**Автор:** [Кишев Беслан]

## Описание
Программа для ведения личного списка прочитанных книг. Позволяет добавлять книги, указывать их автора, жанр и объем, а также фильтровать список для быстрого поиска нужных произведений.

## Функционал
- Добавление книг с валидацией данных.
- Сохранение списка в файл `books.json` (данные не пропадают при закрытии).
- Фильтрация по жанру (поиск подстроки).
- Фильтрация по количеству страниц (поиск книг толще X страниц).

## Инструкция по запуску
1. Установите Python (версии 3.6 или выше).
2. Скачайте файл `main.py`.
3. Запустите программу через терминал:
   ```bash
   python main.py
   ```

## Примеры использования
1. Введите "Мастер и Маргарита", "Булгаков", "Классика", "480" -> Нажмите "Добавить".
2. Чтобы найти все книги длиннее 200 страниц, введите "200" в поле фильтра страниц и нажмите "Ок".
